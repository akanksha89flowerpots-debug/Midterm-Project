# Midterm-Project

# CCSU Mobile App – MIS 310 Midterm Project
# Central Connecticut State University


# OVERVIEW

# This project is a Python Tkinter GUI application built for
# the MIS 310 Midterm Individual Project.
#
# It simulates a simple university mobile assistant that
# performs multiple real-world tasks in one application.



# FEATURES

# 1. Travel Helper
#    - Calculates distance, travel time, and speed
#
# 2. Parking Fee Calculator
#    - Calculates total parking cost
#    - Applies discounts and coupons
#
# 3. Student Grade Calculator
#    - Accepts test scores
#    - Computes average
#    - Assigns letter grade (A–F)



# GUI REQUIREMENTS IMPLEMENTED

# - Main Tkinter window
# - CCSU-themed interface (light blue background)
# - Multiple labels for displaying results
# - 3+ input entry boxes
# - Multiple buttons for different features
# - Output display area (updates dynamically)
# - Fixed window size (non-resizable)



# BUTTON FUNCTIONS

# Button 1: Travel Helper
# - Computes distance, speed, and time
#
# Button 2: Parking Calculator
# - Calculates parking fees
# - Applies discounts/coupons
#
# Button 3: Grade Calculator
# - Calculates average score
# - Displays letter grade




# FILES USED

# main.py        → Main Tkinter application
# examfile.csv   → Data source for GUI buttons
# logo1.png      → CCSU logo image
# logo2.png      → Alternate logo image
